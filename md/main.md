# VOYAGER : ATLAS
**월드맵 — SIMULATION ATLAS**

소넷 박사가 구축한 가상현실 탐사 시스템의 이름은 ATLAS(아틀라스).

ATLAS는 실제 세계의 지형과 환경을 바탕으로 구축되었지만, 단순히 현실을 재현하는 프로그램은 아니다.

서로 다른 기후와 지형, 생태계를 조합하고, 특정 환경 변수들을 비정상적으로 변화시켜 포켓몬의 적응 능력을 관찰하는 시스템에 가깝다.

각 지역은 SECTOR라는 명칭으로 구분하고, 개별 지역에는 고유한 코드네임을 부여한다.

## 플레이 기획 v0.2 — 2026-10-31

현재 단계는 구현 전 수치 초안이다. 실제 포켓몬 능력치·포획·진화·PvP는 별도 기획 대상이며, 아래 탐사 경제는 포켓몬의 희귀도나 전투력 판매를 전제하지 않는다. Firebase/Firestore 사용 예정이지만 이 문서에서는 코드를 다루지 않는다.

핵심 반복은 **파견 준비 → 오프라인 탐사 → 결과 확인 → 보급/제작/연구 중 소비 선택 → 다음 지역 개방**이다. 하루 1~2회, 회당 5~10분 확인으로 주요 성장이 가능하도록 한다. 짧은 탐사는 조합 시험, 긴 탐사는 생활 주기에 맞는 자원 수집이다.

지역 문서는 공통 탐사 보상을 다시 곱하지 않는다. 보상 수치는 탐사 공통, 아이템 이름·제작 비용은 아이템, 해금 비용은 성장, NPC 구매/매각 가격과 재고는 상점 문서를 기준으로 한다. 지역 문서의 해금 설명은 요약이다.

### 파견 준비의 기본 흐름

지역 선택 → 출전 가능한 포켓몬1마리 선택 → 장비2칸에 영구 장비/열매 설정 → 5분·15분·30분·1시간·3시간·6시간 중 선택 → 경로/기타 소모품/예약 확인 → 출발. 상세 가용 조건·독립 시간 예시는 [탐사 공통](sector/exploration.md)을 따른다.

### 의도하는 선택

- 장비2칸을 안전·채집·지역 특화·자동 사용 열매 중 어디에 쓸지 선택한다. 열매도 장비칸을 쓰는 소모품이다. 높은 등급도 칸을 사용하며 모든 기능을 합치지 않는다.
- 계정당 같은 지역에는 포켓몬1마리만, 최대3마리를 서로 다른3지역에 파견한다. 포켓몬·장비 실물은 파견 간 중복 배정하지 않고 지역별 출발/종료 시각은 독립 계산한다. 최대3개 지역을 나눠 탐사하므로 다음 해금 재료, 기존 보급 재료, 공동 연구 기여 사이에 배분이 생긴다.
- 환경 적응 타입은 선택의 이점이며 입장 자격이 아니다. 처음 받은 포켓몬도 장비와 안전 경로로 전 지역을 조사할 수 있다.
- 지역 해금과 기본 장비에는 확률 전용 전리품을 요구하지 않는다. 협력과 거래도 해금의 필수 조건이 아니다.
- 오래 쉰다고 장비나 재료가 썩지 않는다. 연속 출석·실시간 대응·강제 경쟁 순위를 두지 않는다.

ABYSS에 복사돼 있던 숲 드롭, 15분 희귀 보상 표기, 미정 표본 용도, 획득처 없는 의뢰 재료는 이 버전에서 교정했다. 공식 포켓몬 전투 상성 수치를 이 탐사 규칙에 그대로 적용하지 않으며, 탐사 타입 보너스는 공통 문서의 독립 규칙을 따른다.
