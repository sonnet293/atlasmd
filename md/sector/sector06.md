## 고유 위험과 선택

공간 재배열: 위험 HP40. 길을 잃은 로그가 나와도 탐사 시간·예약을 연장하지 않고 공통 사고 손실만 적용한다.

기본 경로: 기록 회랑(안전) / 미기록 방(조사). 조사 경로에서 기억 나침반 계열 장착 시 선택한 C1 또는 C2 +15%.

적응 타입 효과: 공간 감지: C1 +10%, 위험 HP40을20으로 낮춘다.

### 실제 선택 규칙

조사 경로에서는 **유물실(C1 +15%) / 붕괴실(C2 +15%)** 중 하나를 출발 전에 선택한다. 기억 나침반 계열 장착 시에만 적용한다. 안전 경로는 기존 기록을 따라가며 확정 D/R을 지킨다. 미기록 방의 실제 구조는 탐사마다 달라도 보상표/정산은 달라지지 않는다. 동료에게 경로 지도를 매번 클릭해 전송하는 노동 대신 공동 관측 보너스로 정보 공유를 표현한다.

위 경로 안의 하위 선택은 출발 전에 고정한다. 조사 배율은 선택한 한 종류에만 적용하며 다른 종류에는 붙이지 않는다. 타입·장비·협력과 합쳐 C 보정 상한40%. 공통 사고 표의 확률에 장비/경로 %p를 적용하고, 이 지역 연출 때문에 별도 손실 판정을 추가하지 않는다.

## 장비 제작과 성장 목표

- 기초 기억 나침반: RP450 + 발광 산호6 + 절연 섬유6 + 고목의 수액4 →1개. 이 지역 개방 즉시 권한.
- 정밀 기억 나침반: RP700 + 고대 합금8 + 구조물 관측 데이터8 + 고대 렌즈2 →1개. 본인 이 지역 누적12시간 이후.
- RELIC 관측 부착물: RP500 + AD3 + 기억 저장 코어1 + 고대 렌즈2 →1개. 이 지역 누적24시간 이후.
- RELIC 공명 부착물: RP1200 + AD8 + 미궁의 열쇠1 + 기억 저장 코어1 →1개. 이 지역 누적24시간 이후.
- RELIC 기념 배지: RP100 + 미궁의 열쇠1 →1개. 전시용, 지역당1개 한정.

기초형은 자기 지역 사고 -6%p·위험HP20, 정밀형은 -9%p·위험HP0·C2 +10%. 관측 부착물은 자기 C1 +25%, 공명은 전 지역 사고 -4%p·자기 C2 +10%. 모두 장비1칸을 쓴다(배지 제외). 특수 장비도 입장·다음 지역 해금 조건이 아니다.

성장 목표: 귀속 관측과 유물 소비를 분리한다. 미궁의 열쇠는 이름과 달리 입장 열쇠가 아니라 특수 제작 재료다.

다른 시스템과의 연결: 07 해금 합금/구조물 데이터, 09 해금 구조물 데이터/고대 렌즈. 유물은 일반 연구와 공동 분석에 계속 쓰인다.

지역 누적6/12/24/60시간 보상은 공통 성장 규칙을 따르며 별도 무료 소재를 발행하지 않는다. 지역 C1/C2/A/D는 일반 연구, C1/C2/D는 공동 분석에, R/D는 AD 분석에 계속 사용한다. 따라서 다음 지역 개방 이후에도 귀환할 이유가 남는다.

## 보상 예시

안전 경로1시간, 장비/타입/협력/사고 없음: 고대 석편10 + 유적 잔해10 + 고대 합금4 + 구조물 관측 데이터4 + 고대 렌즈1 + RP24. C만 floor(12×0.9)=10이다. E는8% 또는 해당 회차의 보장 조건에 따라1개, S는 나오지 않는다.
