# SECTOR 01~09

[공통 탐사](exploration.md) / [해금 비용·의존 관계](../progression.md) / [전체 소재 장부](../item.md)

지역 기믹은 출발 전 선택하며 방치 중 개입을 요구하지 않는다. 안전 경로는 모든 지역에 있고, 추천 타입은 입장 제한이 아니다. 01 외에는 C1/C2/A/D/R/E/S의7개 드롭만 사용하여 과도한 아이템 증가를 제한한다.

|---|---|---|
| [01 VERDANT](sector01.md) | 보급 열매/식생 채집 선택·독 대응 | 전 지역 열매·수액·안전 보급 |
| [02 ABYSS](sector02.md) | 생태/지질 수거·수압 대응 | 산호·퇴적물·관측 |
| [03 CRATER](sector03.md) | 광맥/화산재층 선택 | 냉각 보급·광석 |
| [04 ARCTIC](sector04.md) | 난방/채빙 선택·3슬롯 운용 | 보온 소재·후속 장비 |
| [05 VOLTEX](sector05.md) | 생산 장비의 간섭과 접지·타입 조합 | 절연 소재·공동 분석 |
| [06 RELIC](sector06.md) | 유물실/붕괴실·확정 관측 | 고대 합금·AD 연구 |
