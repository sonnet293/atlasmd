## 고유 위험과 선택

환경 중첩: 위험 HP40. 출발 화면에 이번 파견의 기준 환경(01~08 중 하나)을 표시하고 끝까지 고정한다. 재접속/취소로 다시 뽑지 못하며 지역 전체 6시간 구간(KST 00/06/12/18시)의 동일 환경을 공유한다.

기본 경로: 고정 관측점(안전) / 중첩 지대(조사). 조사 경로에서 위상 고정기 계열 장착 시 C1 +15%. 다른 지역 장비를 이곳 전용 장비로 간주하지 않는다.

적응 타입 효과: 이번 기준 환경의 추천 타입과 일치하면 C1 +10%, 위험 HP40을20으로 낮춘다. 조건은 출발 전에 확인 가능하며 복합 타입도 한 번만 적용한다.

### 실제 선택 규칙

기준 환경에 해당하는 **01~08 지역 대응 장비**를 장착하면09에서 그 장비의 사고 감소만 적용한다(기초 -6%p / 정밀 -9%p). HP 감소·C2 보너스·조사 경로 조건은 넘어오지 않는다. 위상 고정기 계열과도 사고 감소를 합산하지 않고 더 큰 하나만 쓴다. 따라서 기존 장비로 예고된 환경을 준비하거나 위상 고정기로 상시 대응하는 선택이 생긴다. 하루 환경이 바뀌어도 이미 출발한 탐사는 고정된 환경으로 끝난다. 기록 손상은 D의 이름일 뿐 실제 계정 데이터/창고를 되돌리지 않는다.

위 경로 안의 하위 선택은 출발 전에 고정한다. 조사 배율은 선택한 한 종류에만 적용하며 다른 종류에는 붙이지 않는다. 타입·장비·협력과 합쳐 C 보정 상한40%. 공통 사고 표의 확률에 장비/경로 %p를 적용하고, 이 지역 연출 때문에 별도 손실 판정을 추가하지 않는다.

## 장비 제작과 성장 목표

- 기초 위상 고정기: RP800 + 경량 합금6 + 절연 섬유6 + 고대 합금4 →1개. 이 지역 개방 즉시 권한.
- 정밀 위상 고정기: RP1050 + 안정화 분말8 + 손상된 관측 데이터8 + 위상 결정2 →1개. 본인 이 지역 누적12시간 이후.
- PARADOX 관측 부착물: RP500 + AD3 + 인과 코어1 + 위상 결정2 →1개. 이 지역 누적24시간 이후.
- PARADOX 공명 부착물: RP1200 + AD8 + 역설의 조각1 + 인과 코어1 →1개. 이 지역 누적24시간 이후.
- PARADOX 기념 배지: RP100 + 역설의 조각1 →1개. 전시용, 지역당1개 한정.

기초형은 자기 지역 사고 -6%p·위험HP20, 정밀형은 -9%p·위험HP0·C2 +10%. 관측 부착물은 자기 C1 +25%, 공명은 전 지역 사고 -4%p·자기 C2 +10%. 모두 장비1칸을 쓴다(배지 제외). 특수 장비도 입장·다음 지역 해금 조건이 아니다.

성장 목표: 새로운 무한 전투력 수치를 만들기보다 기존 특화를 교대로 시험하고 종합 연구·기록실을 완성한다.

다른 시스템과의 연결: 손상된 관측 데이터는 일반 의뢰와 종합 연구에, 안정화 분말은 자기 지역 정밀 장비에 사용한다. 기존 01~08의 소재·장비를 대체 발행하지 않는다.

지역 누적6/12/24/60시간 보상은 공통 성장 규칙을 따르며 별도 무료 소재를 발행하지 않는다. 지역 C1/C2/A/D는 일반 연구, C1/C2/D는 공동 분석에, R/D는 AD 분석에 계속 사용한다. 따라서 다음 지역 개방 이후에도 귀환할 이유가 남는다.

## 보상 예시

안전 경로1시간, 장비/타입/협력/사고 없음: 불안정 파편10 + 왜곡 표본10 + 안정화 분말4 + 손상된 관측 데이터4 + 위상 결정1 + RP24. C만 floor(12×0.9)=10이다. E는8% 또는 해당 회차의 보장 조건에 따라1개, S는 나오지 않는다.
