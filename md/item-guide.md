# ATLAS 아이템 도감

[기획·제작 레시피](item.md) / [지역별 드롭](sector/README.md) / [경제·교환](economy.md)

인벤토리와 툴팁에 사용할 아이템 설명 초안이다. **등급·기능은 실제 규칙**, 따옴표 안 문장은 게임 내 분위기 설명이다. 이야기 속 발광·열기·기억·부유 현상은 표에 없는 추가 능력을 주지 않는다. 소재를 소지하는 것만으로 HP·능력치·드롭률이 오르지 않는다. 오랭열매와 복슝열매만 보급칸에서 직접 자동 사용한다.

## 등급 안내

색과 함께 등급명을 항상 표시한다. 등급색은 시각 디자인 제안이며 구현된 UI가 아니다. 제작품에는 위 탐사 최소 시간이 적용되지 않고 레시피·제작 권한이 적용된다. 높은 등급도 모든 역할을 대신하지 않으며, 수집품 등급은 생산 성능을 뜻하지 않는다.

## 표기와 이용 조건

- **소재**: 제작·제출할 때 소모. 재료의 특성을 묘사해도 직접 장착하지 못한다.
- **관측 데이터**: 귀속 연구 소재. 고급 관측 기록과 특급 기록은 등급이 다르므로 서로 대체하지 못한다.
- **장비**: 장착 시에만 작동, 각1칸. 포켓몬당2칸, 내구도 없음·계정 귀속.
- **소모품**: 출발 시1개 소모하여 해당 회차에 적용. 열매와 별도로 파견당1종만 사용.
- **열매**: 별도 보급2칸, 총6개(벨트 사용 시8개). 사용한 수량만 소모하고 미사용분은 반환.
- **수집품**: 기록실 전시용. 장비칸을 사용하지 않고 생산·전투 효과 없음.
- **%p**는 확률의 차이: 사고12%에 -6%p라면6%. 채집 +10%는 해당 기본 수량의10%를 뜻한다.
- 일반·고급 소재 중 거래 가능한 것만 원산 지역을 개방한 유저에게 전달할 수 있다. 모든 장비·가공 표본·데이터·희귀 이상 소재·제작 소모품·배지는 귀속이다.

## 1. 지역별 소재

각 지역 제목의 탐사에서 획득한다. 아래 '일반 연구'는 해당 지역 기본 소재2종 각6개+고급 제작 소재2개+고급 관측 데이터2개를 제출하여 RP60을 받는 의뢰다. '공동 분석'은 기본 소재2종 각12개+관측 데이터4개+RP30을 제출하는 협력 기여다. 정확한 횟수 제한과 소비량은 연결된 기획 문서를 따른다.

- 다른 용도: 일일 제출·일반 연구·공동 분석.
